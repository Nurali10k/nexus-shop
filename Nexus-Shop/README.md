# NEXUS Shop

Демо-магазин электроники на React, Vite, Redux Toolkit и Tailwind CSS. В проекте есть каталог с поиском, фильтрами и сортировкой, карточки товаров, корзина и избранное с сохранением в браузере, оформление демо-заказа, локальные страницы входа и регистрации, профиль, админ-панель каталога и смена статусов заказов.

## Запуск

```bash
npm install
npm run dev
```

Vite откроет приложение на `http://localhost:3000`. Для production-сборки используйте `npm run build`, для проверки стиля кода — `npm run lint`.

## Демо-режим

Каталог товаров и заказы хранятся в Firestore; корзина и избранное — в `localStorage`. Для доступа к заказам с разных устройств войдите в один и тот же Firebase-аккаунт на каждом устройстве. Заказы, созданные ранее в `localStorage`, автоматически в Firestore не переносятся. Пароли аккаунтов в браузере хранятся в виде PBKDF2-хэшей, но клиентское приложение не обеспечивает настоящую аутентификацию или разграничение ролей. В режиме разработки любой вошедший пользователь может открыть демо-панель; в production она закрыта, пока не будет настроена серверная авторизация с ролью администратора. Для production нужны сервер, база данных и серверная проверка доступа. Оплата в демо не списывается.

## Telegram-уведомления (Vercel)

Серверная функция находится в `api/telegram/order.js`. Для её работы задайте в Vercel Project Settings → Environment Variables переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем повторно разверните проект. Не помещайте токен бота в `src/`, `.env` с публичным префиксом или клиентский код. При разработке с обычным `npm run dev` Vite не запускает Vercel Functions, поэтому локально Telegram endpoint недоступен. Перед production необходимо добавить ограничение частоты запросов и проверку заказа по данным сервера; сейчас endpoint подходит только для демонстрации.
